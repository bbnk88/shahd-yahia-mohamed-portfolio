Shahd Yahia Mohamed Salem - Portfolio

Files:
- index.html: portfolio content and structure
- style.css: design and responsive layout
- assets/: certificate images

How to edit:
Open index.html in a text editor (Notepad, VS Code, etc.) and change text/links.
To add your own photo, replace the photo placeholder area in index.html or add your image file and update the <img> tag.

How to publish:
Upload index.html, style.css, and the assets folder to a GitHub repository and enable GitHub Pages.
The portfolio is intended to be shared as a web link. You can also print the page to PDF when a PDF copy is needed.
